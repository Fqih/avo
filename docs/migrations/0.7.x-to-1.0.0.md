# Migration: 0.7.x to 1.0.0 (Production Ready)

Avo v1.0.0 is the official Production Ready release. This guide outlines the key changes, security hardening, and upgrade steps when transitioning from v0.7.x to v1.0.0.

## Overview of Key Changes

1. **Fail-Closed Web Read Authentication**:
   - In v0.7.x, read endpoints (`/api/workspace/tree`, `/api/workspace/file`) permitted unauthenticated reads if the server was running on localhost.
   - In v1.0.0, `require_read_auth` defaults to `True`. All read requests require Bearer token authorization or an active session cookie.

2. **Cryptographic Durable Approvals**:
   - Approvals persisted to SQLite (`pending_approvals`) are cryptographically bound to `run_id`, `tool_name`, `tool_call_id`, a deterministic canonical SHA-256 hash of arguments (`arguments_hash`), and execution timeout.
   - Legacy records without argument hashes are rejected fail-closed to prevent replay attacks.

3. **Git Worktree Isolation & Restoration**:
   - `avo fix`, `avo pr`, and autonomous workflows run inside ephemeral Git worktrees.
   - Worktree creation failure fails closed (`AvoError`), preventing unintended mutations to developer working trees unless `--allow-in-place` is explicitly set.
   - On merge completion or conflict, the repository strictly restores the calling branch and aborts in-progress merge conflicts cleanly via `git merge --abort`.

4. **Installer Checksum Verification**:
   - Both POSIX (`install.sh`) and PowerShell (`install.ps1`) standalone binary installers download and verify SHA-256 checksums fail-closed prior to archive extraction.

5. **SQLite Schema Migrations & WAL Engine**:
   - The SQLite event store tracks versions via `PRAGMA user_version = 2`, enables WAL journal mode (`PRAGMA journal_mode = WAL`), and automatically creates `.bak.<version>` snapshots before schema migrations.

## Upgrade Steps

### Standalone Binary
Re-run the zero-Python installer:
```bash
# POSIX (Linux / macOS)
curl -fsSL https://avo.faqihhakim.tech/install.sh | bash

# Windows PowerShell
irm https://avo.faqihhakim.tech/install.ps1 | iex
```

### Python Package (pip / uv)
```bash
uv tool install --upgrade avo[all]
# or
pip install --upgrade avo
```

### Database Upgrades
Existing `.avo/runs.db` files are automatically migrated to schema version 2 upon startup with an automatic `.bak.1` backup. No manual SQL scripts are required.
