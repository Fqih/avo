Enterprise Reliability Primitives

Engineered to Keep Going Safely

Most agent frameworks treat LLMs as simple while-loops. Avo builds on state-machine rigor, durable event sourcing, and container isolation.

🌿

Git Worktree Isolation

Never corrupt the user's working directory. Code modifications and test runs execute in ephemeral .avo/worktrees/<run_id> workspaces on isolated branches, with guaranteed branch restoration on merge or abort.

🛡️

Dual-Layer Sandbox

Execute untrusted shell operations safely. Uses rootless Linux Bubblewrap (bwrap) with unshared namespaces, or ephemeral Docker containers with network_mode="none".

🔔

Durable Webhook Approval

Pending human authorizations persist in SQLite (pending_approvals) bound to canonical SHA-256 argument hashes. Resumes seamlessly via REST webhooks across process restarts.

🔀

Combo Routing & Failover

One conversation, multiple models. Automatically failover across Anthropic Claude, OpenAI, Gemini, and local Ollama when quotas or rate limits are hit—without losing conversation context.

📜

Event Sourcing & Replay

Every state change appends to an immutable SQLite event log in WAL mode. Step checkpoints allow exact crash-safe resume, deterministic replay, and post-mortem auditability.

🧠

Epistemic Memory & Blackboard

Multi-agent shared scratchpad backed by optimistic locking, plus BM25 keyword recall fact memory with automated secret redaction for API keys and tokens.

Developer Quickstart

Simple to Embed, Powerful to Scale

agent_example.py 
from pathlib import Path
from avo import AgentRuntime, LoopPolicy
from avo.app_tools import GitWorktreeManager, bind_workspace, read_file_tool, write_file_tool
from avo.app_tools.workspace import Workspace
from avo.config import build_provider_from_env
from avo.storage.sqlite import SQLiteEventStore

# 1. Initialize isolated git worktree for this run
manager = GitWorktreeManager(repo_root=".")
worktree_path = manager.create_worktree(run_id="task-audit-01")
workspace = Workspace(worktree_path)

# 2. Build runtime with bounded step and token budget
runtime = AgentRuntime(
    provider=build_provider_from_env(),
    policy=LoopPolicy(max_steps=15, max_total_tokens=50_000),
    tools=[read_file_tool(), write_file_tool()],
    event_store=SQLiteEventStore(Path(".avo/runs.db"))
)

# 3. Execute with deterministic event logging and step checkpoints
with bind_workspace(workspace):
    result = await runtime.run(
        task="Audit dependencies and apply security fixes in isolated worktree."
    )
print(f"Run completed: {result.status.value} (StopReason: {result.stop_reason.value if result.stop_reason else 'None'})")
